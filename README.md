A modern **Quick Commerce Customer Frontend** inspired by leading instant delivery platforms like **Zepto**, **Blinkit**, **Instamart**, **Gopuff**, and **Getir**.

Built with **React**, **TypeScript**, and **Tailwind CSS**, this project provides a scalable and production-ready customer application for grocery delivery, hyperlocal commerce, pharmacies, convenience stores, and multi-vendor marketplaces.
